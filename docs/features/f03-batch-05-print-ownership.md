# F03 第五批：冲印负片所有权

日期：2026-11-12。基于第四批本地验证包继续开发，本批未提交或发布。

## 实现与原因

原冲印只借用负片，外层引擎局部对象在整个冲印期间持续持有它。光谱转换完成后，眩光及后续扫描节点已不再读取负片，却仍与这张完整 RGB32 图面重叠驻留。

Android 一次性导出现在通过 PrintInputScope<Image> 登记负片的局部对象。冲印常量和对比度遮罩准备完成后，阶段链只对同一对象执行所有权转移；完成首个阶段后，原负片即可释放。未登记输入及不同对象上的别名仍按借用处理。线程局部作用域在正常、失败、取消和嵌套情况下恢复登记。

继续使用原冲印阶段和节点、数学、顺序、shader、随机种子与默认效果，不新增 GPU 同步。正常编辑重印缓存、软打样、DI 入口和条带执行保持原调用路径。生成适配由上游锚点核对，桌面共享源码未修改。

## 24MP 对照

相同 6064×4040 Z6II RAW，两个包均使用 Release 原生库。同一 API37 x86_64 模拟器按上批、本批、上批、本批交错，每包每种效果两次。诊断关闭，FIR 实验默认关闭。

| 场景 | 上批临时池高水位 | 本批临时池高水位 | 上批渲染中位数 | 本批渲染中位数 |
| --- | ---: | ---: | ---: | ---: |
| 颗粒与眩光关闭 | 1121.5 MiB | 1121.5 MiB | 1382.1 ms | 1094.2 ms |
| 全部默认效果 | 1401.8 MiB | 1121.5 MiB | 1205.7 ms | 1234.7 ms |

默认效果的全程临时池高水位减少约 280.4 MiB，约 20%。现在第一次达到该高水位的是更早的胶片光晕阶段，眩光阶段没有再次抬高峰值；光谱转换后只剩当前输出一张活跃 RGB32 图面，293,982,720 字节。

临时池高水位不是进程总峰值，不包括全部 CPU、持久缓冲和驱动内存。默认效果计时约增加 2.4%，关闭效果场景约减少 20.8%，仅两轮小样本，不作为真机提速或退化结论；本批确定的收益是默认效果内存峰值降低。原始样本全部保留，不把诊断计时混入正常数据。

8 次 TIFF 完整 SHA-256、6064×4040 尺寸和 146,991,552 字节保持。另一次开启诊断的输出哈希相同。未降低尺寸、位深、JPEG 质量、RAW 解码质量或默认效果。

## 数值、所有权与取消

- 独立 Android 程序 84 个场景、8,531,460 个 Float 样本逐位相等，比较的是量化前完整成片。覆盖彩色负片、反转片、电影片、黑白；单列、奇数尺寸、负值、高光；眩光关闭、零模糊、小范围 FIR、大范围 IIR；直扫、扫描模糊及未登记借用输入。
- 每次参考和消费路径均从相同初始 pipeline 随机状态开始。对比不会用两次任意随机实现的差异冒充画质改变。
- 四个冲印阶段定点取消均无部分输出、无残留活跃临时图。核对取消后相同对象地址复用、别名隔离和嵌套作用域恢复。故障注入仅进入独立程序编译副本，不进入 APK。
- 应用 36 组完整 U16 像素对照通过，包含材料、几何、片边、日期、颗粒、已有负片缓存消费；实际取消与再次打开后编辑缓存恢复通过。
