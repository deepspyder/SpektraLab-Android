# F08：持久自由观景台

日期：2026-11-13。基线为已推送的 `6e758e4`，本批纳入本次功能提交，尚未发布安装版本。

## 功能与交互

观景台保留原有自由照片墙、平移缩放、靠边吸附、重叠透光、灯光和放大镜。新增项目操作条：项目列表、布局撤销、重做与保存。可以命名保存当前画布、打开、另存、重命名和确认删除项目；关闭项目后回到原有临时观景台。删除项目不删除原片、编辑或其他项目。

长按照片或通过无障碍“调整摆放”打开原生工具面板。支持连续角度调节、左右 90°、移到最前或最后；项目内可复制同一张照片形成独立放置，也可添加已有工作台中的照片、移除单次放置。同图重复放置共享来源，拥有各自的 item ID、位置、角度、尺寸和层级。

项目采用显式保存。离开、关闭或切换时，未保存调整提供保存或放弃选项；放弃会恢复已保存布局。一次完成的拖动只生成一次历史，取消手势恢复之前的状态，拖动中不写数据库。撤销最多保留 50 步，属于当前进程内的布局历史；重新打开项目不会恢复旧撤销栈。

物理尺寸模式显式将一个场景单位解释为一毫米，切换保持现有布局且可撤销，不宣称屏幕上的长度已用实体尺校准。可以设置单张照片的毫米宽度，高度按原比例变化，尺寸调整亦可撤销。

界面沿用 Theia 的圆润字体、原生圆角面板与灯箱纸色；照片保持完整矩形与比例，默认不新增边框。控件按现有主题分层，短屏的工具内容可滚动。

## 模块与数据合同

- `core/model/LightTableProject.kt`：不可变项目、场景、照片引用和独立放置；版本化 JSON 及尺寸、坐标、名称与容量校验。
- `core/model/TableGeometry.kt`：旋转、逆向命中、轮廓相交和旋转边缘吸附，共用于画布、重叠及放大镜。
- `data/library/LightTableProjectStore.kt`：独立元数据 SQLite 库，不修改已有照片库 schema；事务保存、完整旧值和 revision 比较、关闭重开及未来格式保护。
- `data/cache/LightTablePreviews.kt`：可丢弃的显示预览，原子写入和有界读取；不作为正式照片或未来项目成品导出的输入。
- `feature/lighttable/FilmCanvasState.kt`：临时手势、场景坐标、层级、布局历史与配置恢复；与存储解耦。
- `LightTableProjectsController.kt`：IO、项目操作、来源解析和有界预览请求；`LightTableProjectUi.kt` 承接原生面板与用户操作。

保持单一 `:app` 模块，沿用现有依赖方向；没有新增大型图像依赖、字体或素材。`GalleryScreen` 继续承接首页与编辑器共用的观景台入口。

场景坐标独立于屏幕 dp 和像素，视口平移以场景单位保存。照片轮廓用于旋转后的点击、可见区域、吸附与重叠；只在实际相交区域透光，旋转放大镜沿用同一变换。无旋转的吸附保留原有对齐规则，重叠计算先做包围盒筛除。

已有编辑绑定稳定的资产及默认版或副本 ID，并记录保存时的编辑 revision；原片重新关联时能沿资产找到新地址。未编辑的导入照片只保存原 URI，不人为创建默认调整。长期来源授权和统一源新鲜度仍属于贯穿的 F07 合同。

项目保存当前显示预览，打开时不自动显影 RAW。编辑版本变化时明确标注为上次保存的预览；编辑版本删除或原片不可访问时保留布局，实际进入编辑时拒绝无效来源并提示恢复访问。预览缓存失效不会删除项目，不用另一张图或未经验证的缓存冒充原片。

项目上限 100 个，每个项目上限 200 次放置，JSON 上限为 2×1024×1024 个 UTF-16 字符。只保存元数据，不复制大 RAW。预览文件长边最多 640px、单项最多 2MiB，磁盘上限 128MiB，按近期访问淘汰；可见小预览长边不超过 192px，最多两路读取，另按需保留最多四张 640px 细节。预览是可丢弃的观片表示，不影响原片、正式图像编辑和导出质量。

SQLite 保存和删除采用事务；错误、过期提交、未知版本或无法识别的字段不重写为默认布局。项目存储与照片编辑存储分离，不把布局操作混入照片调色历史。

## 验证记录

最终同一生产构建完成 29 组、46 条功能记录，包含四处真实进程中断；另完成 1.3 倍字体手机、1600×2560 平板和 2400×1080 横屏，保留 41 张有效原生截图。配置和字体已恢复。实际测试宿主在测试前后及最终重拍后拉回，摘要相同。测试宿主是匹配的调试代码与正式原生库，不将其等同于正式签名安装包的全流程真机验收。

200 次放置的纯布局保存 40 次，中位数 11.150319ms、p95 16.255674ms，运行于 IO；默认参数保存 120 次中位数 1.137248ms、p95 5.606843ms，副本为 1.099641ms 和 4.467228ms。全部为模拟器样本，保存布局、保存参数和渲染是不同口径。旧预览像素摘要保持，但本轮中性、旧色调与曲线计时较先前有波动，原样记录，不声称真机提速或无退化。

Z6II 全尺寸 6064×4040、16 位 TIFF 共 146992152 字节，完整摘要 `62f1d58c709a4bc694ca93f8d552954320f921260fc64dd4c013bf4461926f3f` 保持；首次 11576ms、缓存 2629ms，统计确认第二次命中。旧中性摘要 `3c7e8eee7848fa80cafd64faad1b3c2dd6d90b9de6ecee316d079f0da85fc8d3` 保持。

6 项原生库、94 项引擎素材、2 项许可证素材、Manifest 与共享引擎源码保持。候选包 `app/release/v0.1.5-f08-lighttable-projects-final/Theia-v0.1.5-lighttable-projects.apk` 为 55681821 字节，SHA256 `ac36d85c682665bea943b634fbcf57df00260cb7bdd5bec17a4dc9c25e059d9f`，仍为 0.1.5、versionCode 6，原证书 V1/V2/V3 与双 ABI 通过，未发布。

最终验收结果、模拟器配置、APK 摘要、原生库与素材比较、截图和性能样本记录于忽略目录 `.tmp/lighttable-projects/verification.json`。历史失败及各次构建分目录保留，不能将不同构建的测试混称为同一最终结果。

首轮编译发现 Kotlin 属性 setter 与 `setMillimeters` 的 JVM 名称冲突，改为 `changeUnits`。首轮 UI 测试将同名对话框标题误当保存按钮，修正为寻找真实可操作的控件；原功能断言保留。随后修复放弃调整仅导航却仍保留内存草稿的边界、同项目重开后可见预览请求未重启，以及进入暗房的完成回调被处理中保护拦截的边界；对应恢复场景、预览重新就绪及实际编辑交接断言均保留。旧相册与编辑版本命名回归另遇输入框无障碍节点尚未就绪，截图显示输入框正常，统一给命名测试补条件等待，未移除任何功能断言，也未因此修改生产命名功能。

综合回归还发现既有图库任务登记的竞争：极快完成的 IO 可能先执行收尾，再登记 `load` 句柄，使列表已读出但仍处于 loading。刷新、打开、恢复工作台与源校验统一改为先登记 LAZY 任务再启动；原片恢复 UI 额外连续刷新 32 次，保留原超时和截图证据。此修复不改变数据库内容或图像算法。

本批不把模拟器耗时当作 ARM 真机性能，也不把可见预览尺寸解释为正式导出尺寸。原有图像数学、RAW 解码、胶片/相纸资源和编码质量保持。

独立视觉复核对 41 张有效原生截图给出 `ship`，无必须修复的视觉项；此结论不替代真实触控、性能或图像验证。主题核对确认复用既有配色、圆润字体与原生 Material 组件，`DESIGN.md` 和 `.impeccable/design.json` 摘要保持，既有 Shapes 名称文档差异仅记录。
