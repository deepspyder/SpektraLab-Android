# 胶片与相纸：按住原图和前后对比

日期：2026-11-12。本批在参数边界修复之上完善选片交互，未提交、push或发布。

## 行为修正

- 胶片/相纸预览按住临时显示已解码的原图；松手、手势取消或离开预览后恢复冲印效果，不改参数和编辑记录。
- 原来对比按钮只是切换到原片，现在复用暗房已有的BeforeAfterPreview：左侧原图、右侧当前完整冲印成片，分界线可拖动，也可通过无障碍进度动作调整。
- 对比状态下由分界线拥有拖动手势，不被按住原图抢占；点击关闭回到当前成片。
- 对比按钮移至右上角，避开底部原图/冲印标签；按住说明仅在普通查看模式出现。
- 相纸切换保留对比模式并使用最新成片；切换照片清除前一张的对比/按住状态，直接进入相纸和离开后再次进入行为一致。
- 只有照片区域接收按住手势，完成、返回、分界线与对比按钮保持可操作。源图或成片尚未就绪时禁用对比。
