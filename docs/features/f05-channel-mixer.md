# F05 第一批：通道混合

日期：2026-11-12。本批推进新编辑功能，未提交或发布。

## 使用入口

打开照片 → 调色 → 通道混合。选择红色、绿色或蓝色输出通道，再调整三个输入的贡献比例。右侧显示实际百分比，支持单项还原、当前通道还原和全部还原。控件沿用全局圆体、炭灰、暖纸文字、琥珀选中和圆润轮廓；默认折叠，不挤占现有照片预览。

拖动只修改当前成片调色，不重新显影胶片。按下到松手为一个历史事务；取消、切图、离开面板时恢复已提交值。键盘和无障碍继续使用 Material Slider 的范围语义。未知版本或损坏的通道混合数据原样保存，不静默丢弃；明确还原后才恢复编辑和导出，撤销可找回原始数据。

## 算法和兼容合同

- ChannelMixer version 1：三行三列 RGB 矩阵。每项保存相对单位矩阵的 -100 至 +100 百分点偏移；同色输入显示 0% 至 200%，跨色输入显示 -100% 至 100%。不自动归一化。
- 三行均读取同一个输入像素，分别按原 R、G、B 顺序求和；在 HSL 之后、旧色彩平衡之前执行，不额外进行中间 clamp。保持现有编码空间及旧三段 temp/tint 数学，不能将本批视为整个色彩空间算法迁移。
- 中性矩阵完全跳过计算，旧 sidecar 不写入 channel_mixer 字段，不激活新的 native 调色路径。非中性对象显式写入 version 1。
- 模型不可变，矩阵只在参数变化时准备；内层逐像素不分配对象。复用现有最多 32 行 native CPU 条带，预览和 JPEG、PNG、TIFF 共用 Grade。未增加整张浮点图片或 GPU 工作集。
- JNI 符号和方法签名不变，颜色参数兼容原 26 项及扩展 36 项布局；原生库因新增通道计算发生变化。
- 编辑快照、sidecar、撤销重做和现有参数复制全部保存新矩阵；复制继续保留目标构图。现有保守缓存键包含完整编辑快照，新字段变化不会误用旧请求。

- 中性新增参数对 196,608 个既有标量 Float 样本逐位保持；已有曲线/HSL 数学与完整流程回归通过。
- 真实触摸拖动、系统取消、无障碍调节、输出通道切换、每项/每通道还原、撤销重做、重开切图、当前参数复制、未知数据恢复及单张和批量三格式导出通过。实际 PNG 整图像素与参考一致，不只比较缩略图。
