# F03 第四批：DIR 与颗粒图面生命周期

日期：2026-11-12。上一批已按用户要求提交并推送至 master：b7b6299。本批是随后开发的新任务，尚未提交或发布。

## 实现

Android 一次性导出的胶片阶段转移 DIR 输入所有权。校正图的 GPU dispatch 和 flush 完成后，释放已无后续读者的 CMY 图；原曝光图与校正图合成完成后，释放两张输入，再执行原有曲线插值。取消或失败通过计数句柄释放局部中间图，不公布部分输出。

DIR 计算体由 AndroidExportDir.cmake 从当前上游源码提取并注入生命周期释放，保留原公式、数据、GPU shader、运算顺序和材料分支；上游锚点变化会中止构建。正常预览、缓存重印及条带执行继续使用原节点。共享桌面检出未修改。

默认颗粒在原密度偏移 affine 完成后，释放不再参与末次模糊的原始颗粒图。简单颗粒与分层颗粒都保持原模糊条件、位深、随机种子及算术顺序；原有节点和 mixture flush 不删除。额外释放前保留 flush，遵循 GPU 完成后复用缓冲的要求。

## 内存与耗时

24MP Z6II RAW 为 6064×4040。DIR 完成合成后活跃临时图只剩合成结果一张，293,982,720 字节。最终颗粒阶段没有再次抬高此前光晕阶段的高水位。

| 24MP 场景 | 上批临时池高水位 | 本批临时池高水位 | 上批渲染中位数 | 本批渲染中位数 |
| --- | ---: | ---: | ---: | ---: |
| 颗粒和眩光关闭 | 1401.8 MiB | 1121.5 MiB | 1131.3 ms | 1189.3 ms |
| 全部默认效果 | 1401.8 MiB | 1401.8 MiB | 1170.9 ms | 1144.9 ms |

关闭颗粒与眩光时，全程临时池高水位减少约 280.4 MiB，约 20%。默认效果的高水位仍约 1401.8 MiB，首次达到该值的节点已由 DIR 转移到冲印眩光。只说默认整体峰值下降是不成立的；本批实际减少 DIR 和颗粒阶段的重叠驻留，并为后续冲印优化定位了下一处峰值。

计数不是进程 PSS、CPU 峰值或驱动实际回收量。计时来自同一 API37 x86_64 模拟器的两轮交错采样，关闭效果场景约增加 5.1%，默认效果场景约减少 2.2%，小样本波动不能作为提速承诺。本批优先证明资源生命周期和完整像素保持，不宣称大幅加速。

中间 DIR 单独优化后，颗粒仍产生五图面高水位，因此继续补齐颗粒最后读者释放。原 DIR 单独样本保留在 comparison-delivery，最终对照在 comparison-final。诊断样本与正常计时分开，FIR 实验继续默认关闭。

## 数值及取消验证

- 独立 Android 原生程序 96 个场景、9,750,240 个 Float 样本逐位相等，直接比较完整负片，不依赖 U16 量化掩盖差异。覆盖彩色负片、反转片、电影片、黑白；单列、奇数尺寸、非均匀通道、负值、高光、边缘；DIR 关闭、无扩散、小范围 FIR、大范围 IIR、零强度；简单及分层颗粒、颗粒模糊、染料云、微结构和强度混合。
- 同一初始 pipeline 随机状态比较，不用不受控的两次随机实现作哈希断言。3 个 DIR 内部取消检查点通过，取消后无部分输出、无活跃临时图。故障注入只进入独立程序编译副本，不进入 APK。
- 首次尝试通过应用进度匹配 DIR 节点取消失败。核查确认公开 progress 在渲染期间统一返回 rendering，测试前提错误；保留失败日志，移除这一错误测试，保留原有实际取消与重新打开测试，内部定点取消改用上述独立程序。
- 应用一次性导出的 36 组完整 U16 对照通过，包含全部胶片家族、兼容相纸、几何、片边日期、颗粒及已有负片缓存消费；后续普通编辑仍保留缓存。
- 新旧最终包 8 次 24MP RAW 完整 TIFF 摘要、尺寸及字节数一致。
