# T06：旧编辑记录迁移原型

日期：2026-11-13。独立 SQLite 沙盒原型，尚未接入正式启动、导入、编辑或图库。应用身份、版本、原有 sidecar 写入路径和用户界面保持。本批未提交或推送。

## 本批实现

- 区分源资产 Asset、位置 AssetLocation 和编辑版本 EditVariant。默认编辑版本与虚拟副本共享同一个源资产，只保存参数，不复制 RAW 或像素平面。
- 以提供方和文档身份建立 source key；没有文档 ID 时使用完整 URI。文件名、媒体行号、相同字节和相同 SHA 均不是跨位置自动合并的充分条件。身份限定在当前应用数据范围，不承诺绝对路径跨安装有效。
- SourceProbe 显式读取源头信息并以 64KiB 缓冲流式计算完整 SHA-256；BitmapFactory 只读取 bounds，EXIF 仅读取尺寸和方向。可读取、丢失、无权限和暂不可用状态分开，管道输入不要求 seek。该探测目前只由原型和测试显式调用，不进入日常预览热路径。
- 旧 key 到新身份的映射由实际 URI 的证据绑定提供。无法反查 URI 的旧记录保留待关联；同一旧 media key 对应多个来源时标记歧义，不猜测。
- 原记录与会话索引先归档后写数据库。备份包含原始文本字节、校验摘要、大小、源绑定、顺序和当前位置；数据文件同步后原子发布 manifest。优先读取 AtomicFile 的备份文件，不恢复或删除正式目录内容。未完成的批量日志要求先完成既有恢复，再捕获副本。
- 每条迁移在同一事务内写入资产、默认变体和迁移标记。唯一索引约束每资产一个默认变体，外键约束引用。会话槽位保持旧顺序、重复放置和缺源位置；后续明确关联可补齐空槽，不重排照片。
- 迁移可重入。已迁移项以新库为权威，重新运行旧备份不会覆盖新编辑；旧 payload 或源 revision 变化记录 SOURCE_CHANGED 并保留原数据。
- 沙盒 gateway 验证唯一写入者：迁移前只从副本读取，迁移后只从 repository 读取和写入。普通 sidecar 和备份不被同步回写。revision 乐观检查阻止旧窗口覆盖新编辑。
- 未知顶层扩展、工具版本和错误类型保留为只读编辑记录，原始 JSON 不会用旧参数默认值重写。损坏或过大 sidecar 保留归档并标记 INVALID。未知数据库版本拒绝打开，不重建数据库。
- 显式原片重定位需要完整指纹、字节数、类型、尺寸和方向匹配；只新增位置引用，不改变已有编辑身份。缺源不删除参数或会话位置。

## 分包与访问边界

`core.model/LibraryModels.kt` 定义不可变身份和迁移值；`data.library` 管理探测、归档、repository 和沙盒访问；`EditStore` 只增加两个未接入正常流程的原型适配方法。未引入新的第三方依赖，使用 Android 已有 SQLite API。

本批建立 assets、locations、variants、migrations、migration_attempts、sessions 和 session_items 的测试 schema。相册、评级、色标、正式照片列表及可视虚拟副本入口不属于已完成内容。不得把该测试库直接改名后当作正式升级迁移发布。

## 验证

最终同一构建 20 组、37 条记录全部通过，测试设备为 API37 x86_64 模拟器；包含19组正常回归及1组真实进程恢复验证。完整证据 `.tmp/library-migration/verification.json`。

- 身份与归档：本地文件、可seek内容URI和非seek管道完整摘要一致；提供方、URI位置、同编号42和同名不自动合并；拒绝无权限和离线输入，取消可停止探测；备份优先读取、独立目录、pending批次拒绝及篡改备份零写入通过。
- 映射和唯一写入：默认资产与变体、重复放置、待关联会话槽、当前位置、三次重复迁移、关闭重开、旧备份不覆盖新编辑、虚拟副本参数独立、EditStore旧key适配通过。
- 异常和并发：5处事务checkpoint故障注入后重开及二次恢复通过。两个独立SQLite连接对同revision保存只有一个成功，旧版本不能覆盖新编辑。数据库版本99拒绝打开且原表保留。
- 真实进程终止：RECORD_WRITTEN阶段终止后资产写入回滚，RECORD_COMMITTED阶段终止后保留已提交记录；重新启动后两次续迁均无重复，源图、旧记录及归档保持可读。两份预期的Process crashed原输出保留。
- 未知和缺源：损坏、超限、未知schema和工具数据、无URI和无权限记录均保留；歧义不猜测，后续明确关联会补全旧会话空槽；相同字节的不同资产不合并。重定位不匹配的hash、类型、大小、像素和方向被拒绝。
- 图像一致：迁移前后组合曲线、HSL、通道混合、色轮、暗角的sRGB和P3标量与native预览逐像素一致；100422字节TIFF完全相同；胶片前几何delta一致。
- 已有复制预设、曲线、HSL、通道和色轮、编辑边界、任务队列、导出三格式与元数据、RAW访问及取消、导入、智能显影和长按原图完成回归。
