# F07 第三批：相册、星级、色标与组合筛选

日期：2026-11-13。本批扩展已保存照片图库的整理能力。上一批图库与原片恢复代码已以 `f06997c` 提交并推送至 `master`；本批开发与验收证据单独记录。

## 功能与操作

图库上方提供相册选择、筛选和管理相册。可创建、重命名、删除相册；照片可同时归属多个相册。删除需要确认，只删除相册与成员关系，不删除原片、照片记录、调整、星级、色标或工作台。

每张照片菜单的“整理照片”打开原生底部面板。星级为 0 到 5，0 表示未评级；六类色标包括无色标、红、黄、绿、蓝、紫，颜色同时配有文字。相册归属、星级和色标作为本地草稿，在点击保存后同一事务提交；取消、关闭或系统返回不会写入草稿。保存进行中禁止再次提交和手势关闭，失败保留草稿并提示。

可以组合筛选相册、最低星级和色标，也可以只看未评级、无色标。当前结果数与总照片数可见，筛选为空时说明没有匹配结果并提供清除操作，不会误导成图库没有照片。删除当前筛选中的相册后回到全部相册，不留下看不见的失效条件。筛选不会改变工作台或批量导出的选择。

## 实现与性能边界

生产数据库在事务中从 v2 升级到 v3，新增 `photo_marks`、`albums`、`album_members` 和索引。标记与归属绑定稳定 asset ID，因此原片重新关联后仍保留。编辑参数、编辑 revision、最近编辑时间、源校验和工作台不因整理而改变。

通过 `EditStore` 统一串行访问。整理使用自己的 revision 与完整旧值比较，防止旧面板覆盖新标记或相册删除；所有标记和归属在同一事务更新。相册名进行 NFC 正规化，去首尾空格，大小写无关去重，限制 1 到 40 个 Unicode 字符且拒绝控制字符。上限 200 个相册，超限保留现有内容并提示。

列表和组合筛选在 SQLite 中执行，60 条分页；同一事务返回照片页、相册计数、匹配数和总数，查询值全部绑定参数。整理 IO 不调用 RAW 解码、图像引擎或导出。图库缩略图仍按可见行和小缓存按需读取，不为筛选解码整库。元数据整理无需读取原片，离线照片仍可整理。

未新增依赖、字体或光栅素材，沿用 Theia 主题和 Material 圆润控件。没有修改图像数学、native 引擎、RAW AHD、尺寸、位深、编码质量或胶片默认效果。

## 验证

证据位于忽略目录 `.tmp/photo-organization/`，最终汇总为 `verification.json`。每个构建、失败、修复和复测保留独立记录。

首轮发现 SQLite 的 `COALESCE` 表达式与文本绑定星级比较导致空结果，改为显式 `CAST(? AS INTEGER)`，原断言保留。修复后 601 条记录独立预期逐页核对通过，包含相册、星级、色标、未评级、无色标、组合条件、无匹配、重复检查和参数注入字符串。六类首页查询首轮模拟器样本约 1 到 2ms，不作真机耗时承诺。

存储专项覆盖真实 v2 schema 升级、名称与 Unicode、重复名、标记与成员关系事务回滚、删除回滚、过期旧值拒绝、无变化保存、关闭重开、原片重新关联、编辑继续保存，以及删相册后原片、调整、标记和工作台保持。真实 UI 完成新建、改名、取消删除与确认删除、取消标记草稿、保存标记及归属、组合筛选、空结果和清除、继续编辑；整理时 native 底图引用保持，编辑参数未变。

最终同一生产构建完成 23 组回归，加上真实进程终止恢复，共 24 组、36 条记录通过。覆盖实际旧 APK 写 v2 独立库并覆盖升级到 v3，所有编辑与标记的恢复断言保持；测试不清当前应用数据。事务提交前后真实终止进程，重开结果分别为整体回滚和完整保留，原片、编辑版本和工作台无变化。故障注入不是满盘实测。

另完成 1.3 倍字体、1600×2560 平板和 2400×1080 横屏的真实新建相册、草稿取消、保存评级色标与归属、组合筛选流程。截图包含 9 种正常手机状态以及每类屏幕 7 种状态。模拟器恢复为 1080×2400、420dpi、字体 1.0。测试宿主在完整测试前后从模拟器拉回，摘要相同。

最终 601 条记录的六类首页查询约 1.38 到 2.12ms，120 次普通保存中位数 0.792673ms、p95 3.961859ms；上一批采样为 0.754178ms、p95 3.808223ms。保留全部样本，差异属于本轮模拟器测量，不能承诺真机固定速度。RAW 样本 6064×4040、16 位 TIFF 共 146992152 字节，完整 SHA256 仍为 `62f1d58c709a4bc694ca93f8d552954320f921260fc64dd4c013bf4461926f3f`；首导 8684ms、缓存 2340ms。其他既有 RAW 导出摘要保持。
