# F14 · CineStill 800T 与背反射光晕

更新：2026-11-14。用户指定优先开发 F14，F10 没有随本批推进。本批不提交、推送或发布版本。

## 模型来源与边界

参考本地 `../SpektraLab`，提交 `1952c63537ec576d24422f1065b12495631346a5`：

- `engine/resources_product/profiles/cinestill_800t.json`：以 `kodak_vision3_500t` 为基础的别名，只覆盖名称、静态摄影用途及没有防光晕层三个信息。
- `engine/src/core/halation_psf.hpp`：每通道四个带符号高斯分量、基片厚度单位的半径，以及红/绿/蓝返回光强度 `0.30 / 0.03 / 0.003`。
- `engine/src/core/params.cpp`、`engine/src/pipeline/pipeline.cpp`、`engine/src/shaders/nodes.metal`：光晕预设、背反射混合和高光余量公式。

CineStill 没有另造一套“实测”感光数组；运行时继承未修改的 Vision3 500T 数据。此处是原项目模型的 Android 移植，不是独立 CineStill 测量数据，也没有在本机运行 macOS Metal 作整引擎对照。

Android 原来构建的 `../SpektraLab-Windows/engine` 仍是 `6b5aacaf72190039fc9c70b0352cff692f789718`。本批没有整体升级共享引擎，也没有修改两个桌面项目。新增资源的来源与许可见 `app/src/main/engine-resources/NOTICE.md`；既有材料数据与 CC BY-SA 4.0 归属保留。

## Android 实现

`AndroidHalation.cmake` 在各 ABI 的构建目录生成源码覆盖层，所有引擎翻译单元共同使用它，避免 Params/Profile 布局不一致。覆盖层只复制源码，材料、常量表和第三方依赖仍使用既有来源。每处补丁检查唯一锚点，参考代码漂移时构建明确失败；内容不变时不重写生成文件。

新增内容分为三层：

1. **材料解析**：单层别名保留基础胶片身份，并在中性滤色表没有独立 CineStill 行时回退 Vision3。拒绝非法路径和嵌套别名，不复制测量数组或新增伪造中性滤色表。
2. **光学模型**：只有版本 2 且胶片本身没有防光晕层、或用户明确移除该层时，才采用原项目四分量背反射 PSF。沿用已有 FIR、IIR、带符号混合及全尺寸导出的所有权和内存适配。原引擎已经有 `sqrt(amount)` 面积缩放，本批没有重复缩放或修改旧半径公式。
3. **高光余量**：在整帧 boost 后、overscan 前，对实际帧峰值做归约。两个 smoothstep 门控分别约束接近截断和足够明亮的区域；同一 RGB 增益保留颜色。默认 4 EV，可调 0–8 EV。新增 Vulkan 内核处理超过单行工作组上限的大图和不满工作组的尾部。

高光余量是为接近峰值的亮部补充模拟曝光，不会恢复照片中已经丢失的细节，不是 F19 HDR。0 EV 只关闭该补偿，仍然使用背反射 PSF；关闭光晕、光晕面积为零或保留防光晕层时不额外启用补偿。

## 旧编辑兼容

| 情况 | 实际行为 |
| --- | --- |
| 旧照片或旧预设没有新字段 | 使用经典模型 1、高光余量偏好 4 EV；经典模型不执行新高光节点 |
| 在材料选择器明确选择 CineStill 800T | 启用背反射模型 2；不会在载入旧照片时自动迁移 |
| 有防光晕层且未移除 | 保持既有光晕输出，即使模型偏好为 2 |
| 切回经典，再切回背反射 | 保留高光余量偏好；实时刷新光晕预设 |
| 未知、小数、错误类型的模型版本 | 明确拒绝读取/原生更新，保留原始记录，不悄悄取整或降级 |
| 无效或越界高光余量 | 明确拒绝，原生参数更新保持原子性 |

两项 wire 字段是 `halation_model_version`（默认 1）和 `halation_headroom_ev`（默认 4）。它们接入编辑 JSON、原生 delta、快照、撤销、复制、保存重开、预设、正式缓存以及单张和批量导出。分组归属为 **FILM**；只复制材料的 **MATERIAL** 分组不会顺带覆盖光晕偏好。旧 FILM 预设缺少新字段时仍按经典模型读取。

## 界面与素材

- 胶片库增加 CineStill 800T，电影胶片分类可找到；选择后继续使用原有实时预览、按住原图、原图与冲印对比及相纸配对。
- 控件位于“放印 → 乳剂与暗房效应”。没有防光晕层时显示“经典 / 背反射”选择，背反射下增加“截断高光余量”和用途说明。
- CineStill 的防光晕层开关显示关闭并禁用，解释其本身没有该层。没有照片、导入、导出或批量应用时禁止修改；关闭效果时保留参数并禁用相关调节。
- 沿用现有深色圆润主题与原生控件，不重排整套编辑器。手机、大字体、平板、横屏均以生产界面核对。
- 新标签延续现有相纸标签风格。384×448 透明无损 WebP 为 12,046 字节；可编辑 SVG 和高清 PNG 母版留在设计目录，不进 APK。它是示意标签，不是官方包装摄影。原有 31 张运行时图片保持字节不变。

## 验证证据

本批证据保存在 `.tmp/f14-cinestill/`，汇总为 `verification.json`；最终界面截图和独立复核在 `.impeccable/review/f14-cinestill-final/`。横屏审阅以其中 `landscape-supplement/` 的分状态截图为准，原 `landscape/` 的不完整滚动截图只保留为过程证据。

- 开发前的红测试明确报告生产目录缺少 CineStill，之后使用实际 Vulkan 成功载入和渲染。
- 关闭光晕后 CineStill 与 Vision3 的完整 U16 相同；背反射 CineStill 与显式移除防光晕层的 Vision3 相同。经典、背反射和高光余量分别产生可验证变化。
- 保留防光晕层、关闭效果及零返回光时，完整 U16 与兼容参考相同；实时模型往返刷新正确，非法原生 delta 不产生部分更新。
- 旧的 31 组胶片/相纸完整 U16 文件与此前固定基准逐字节相同。现在目录为 25 款胶片、9 款相纸，覆盖 32 组兼容材料参考。
- 原有 96 项引擎/许可证素材与上批 APK 相同，仅新增别名、说明和高光 shader 三项。PSF 头文件及别名 JSON 与原项目逐字节相同。
- 独立 GPU 核对包含 24 个用例、3,932,361 个被比较的通道样本，覆盖标量公式、阴影/关闭精确保持、超过 1677 万像素的折叠调度，以及 FIR/IIR 带符号混合。公式的最大 `abs(error) / max(1, abs(reference))` 为 `6.06898e-6`；该数值不是对所有场景声称绝对误差接近零。
- 真实生产界面的模型自动启用、高光余量调节、撤销/重做、保存重开、不同照片隔离和分组复制通过。PNG、JPEG100、TIFF16 的单张/批量解码像素或 TIFF 栅格逐一一致，尺寸保留。JPEG100 本身仍是有损编码，不据此声称格式无损。
- 真实 Z6II NEF 的 6064×4040、16 位 RGB、未压缩 TIFF 保留全尺寸，146,992,152 字节；首次与缓存文件 SHA-256 相同：`13ecf2f7c248b4066b6dc37b1728aca5f2e73e894758bee2f345208759cf1a3c`。确定性核对只关闭随机颗粒和眩光，不降低尺寸、位深或 RAW 显影质量。
- 正式一次性导出与交互全尺寸结果按 U16 核对，包括新模型的 0/4/8 EV；在途物理模型导出取消、会话释放和再次打开编辑继续核对。

同尺寸性能表、最终回归数量及四种配置结果以 `verification.json` 为准；模拟器时间不代替手机速度或温控验收。发布候选仍为 0.1.5/code6，沿用原更新证书，V1/V2/V3 验签通过，没有发布新版本。

### 本轮实测

最终生产候选完成 **32 组、202 条功能记录**。另外四种配置各完成真实生产界面的选择、调节、保存、撤销/重做与模型往返流程。短横屏只隐藏重复尺寸信息和参数标题，保留材料入口，恢复实际可操作的参数高度。

独立界面完整复核的处置为 **ship**，仅覆盖新胶片标签、光晕控件及该横屏修订；不能把视觉复核用作引擎准确性或 ARM 验收。首次横屏截图缺少对应滚动位置，被要求补拍；补拍后进行了新的完整复核，未把失败的证据轮当作通过。

旧功能性能采用“新版 A → 旧版 e3a6ecd → 新版 B”的同模拟器、同分辨率序列，每个固定参数热身后取三次中位数。52 组后期固定输入像素摘要全部相同，88 组原生参数保留相同输出尺寸。

| 观测项 | 旧版 | 新版 A | 新版 B |
| --- | ---: | ---: | ---: |
| 24 款旧胶片切换，各项中位数的中位数 | 158.32 ms | 163.67 ms | 156.54 ms |
| 9 款相纸切换，各项中位数的中位数 | 78.69 ms | 81.45 ms | 74.55 ms |
| 52 组后期的各项中位数之和 | 3309.26 ms | 3243.50 ms | 3354.96 ms |
| 88 组原生参数的各项中位数之和 | 16093.30 ms | 16243.94 ms | 15810.24 ms |

后两行是用来观察整体变化的参数中位数之和，**不是一次导出耗时**。没有看到整体数量级退化，但个别样本有明显波动，不能据此承诺每一项都更快。部分序列与补充截图测试的编译重叠，故这也是粗粒度回归观测，不是隔离的微基准或尾延迟验收。

新模型在 1600×1200 下的模型切换、高光余量、面积、散射、增强和胶片切换分别记录三次时间；最终一轮中位数约为 **153 / 138 / 137 / 140 / 246 / 171 ms**。先前同构建原生库的一轮约为 134–144 ms，原始波动均保留，不挑较快一轮冒充稳定速度。正式输出没有为这些测量缩小尺寸或改变位深。

最终 CineStill 24MP TIFF 的本次首次/缓存观测为 **9498 / 1094 ms**。旧版中性及调色后的全尺寸 TIFF 也复核到原摘要 `3c7e8eee…85fc8d3` 和 `62f1d58c…926f3f`。交互测试中的原生冲印保留生产随机眩光，其跨轮次摘要会随拖动期间接受的渲染次数变化；每轮都另按自身最新原生结果核对最终显示和保存参数，不能用该随机样本代替固定输入画质对照。

### 构建与重现

资源沿用项目的同步方式：先运行 `python tools/sync_resources.py`，再运行
`python tools/compile_shaders.py <glslang可执行文件>`，然后构建 Android APK。
前者将 Android 自有别名和说明叠加到已有资源，后者合并 Android 自有 shader
与旧引擎 shader。它们不需要下载一套新材料或修改共享桌面源码。
`tools/native/halation_model_audit.cpp` 可通过
`python tools/build_export_fir_audit.py --audit halation --output <新的证据目录>`
构建独立核对程序；其链接的是实际 Release 原生库，没有向产品 APK 添加测试入口。

仪器测试入口为 `cinestill`、`cinestill-native`、`cinestill-layout`、
`cinestill-raw` 和 `cinestill-performance`。RAW 用例需要已有的显式 Z6II 测试原片；
不把用户图库中任意照片当作测试文件，也不清空应用数据来获得测试通过。

## 剩余验收

F14 核心代码与模拟器验收分开记录。ARM 真机的 GPU 驱动、显存峰值、温控后延迟及真实夜景观感仍需验收；不能用 x86_64 模拟器代签。50MP、超宽图、跨机型压力测试也不在这次 24MP 样本之内。F03 原有大图/IIR 风险、F10 和 F19 的未完成范围全部保留。

本批没有减小正式导出尺寸、压低位深、改 RAW AHD 显影或降低编码质量。新模型增加真实光学计算，不能承诺与经典模型耗时完全相同；性能核对分别记录新模型调参和旧功能的同尺寸对照。
