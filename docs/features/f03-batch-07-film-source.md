# F03 第七批：前处理后释放源图

日期：2026-11-12。在第六批未提交工作上继续开发，本批未提交或发布。

## 实现

排查 DIR 扩散时发现，IIR 前后向递推仍需保留旧累加值，直接将输出覆盖到旧累加图会改变像素，本批不改其数学。另一个明确的重叠来源是原始源图：它在测光和前处理结束后已经没有读取者，却仍与 DIR 全尺寸工作集同时驻留。

一次性导出先将完整尺寸交给 pipeline，并计算和缓存统一测光值，再清除 session 源图及 tier image 的多余持有者。保留 TierState 对象，继续写回曝光与片边元数据。FilmInputScope<Image> 登记当前局部输入，仅在 film_prefix 成功完成后退休同一个对象。

前处理结果 cur 持有自己的计数句柄，即使与源图共享同一缓冲也继续有效，直到后续最后一个读取者结束。普通编辑、非一次性导出、缓存负片分支及条带路径继续原语义；失败或取消按既有入口关闭消费会话。线程局部作用域按身份匹配，结束后恢复先前登记。没有删除任何 GPU flush 或增加像素计算。

## 24MP 内存核对

| 测量 | 上批 | 本批 |
| --- | ---: | ---: |
| DIR 扩散结束时持久缓冲 | 315,103,004 字节 | 672,284 字节 |
| 全程临时池高水位 | 1121.5 MiB | 1121.5 MiB |

默认 6064×4040 RAW 的前处理完成后，退休原源图释放 293,982,720 字节，约 280.4 MiB；清除测光层级图另减少约 19.5 MiB。与上批相比，DIR 阶段持久缓冲合计减少 314,430,720 字节，约 299.9 MiB。

这些是特定阶段 GPU 持久缓冲计数的差值。临时池高水位本批没有下降，不能将两者混为一项，也不能据此直接推算进程或驱动总峰值。自动曝光关闭等前处理直接共享原缓冲的情形，会由后续计数句柄继续保护原数据；退休局部对象并不等于强制销毁仍在使用的缓冲。

## 数值和边界

- 独立 120 场景、12,187,800 个完整负片 Float 样本逐位一致。参考和消费路径使用相同初始 pipeline 随机状态；消费路径登记源图，前处理后要求局部源图已退休，完整负片继续可读。
- 涵盖负片、反转片、电影片、黑白，关闭和开启光晕、散射和背反射、混合模糊范围、镜头模糊及颗粒，包含前处理共享缓冲。三个 DIR 内部取消检查点均无源图、部分结果或活跃临时图残留。嵌套对象身份、外层登记恢复及同一对象地址复用通过。
- 应用完整 U16 对照增加自动曝光关闭及关闭自动曝光后的裁剪两种场景，从 36 增至 38 组；既有片边、日期、不同材料、颗粒、已有负片缓存消费及后续普通编辑缓存仍通过。实际取消和重新打开恢复通过。
