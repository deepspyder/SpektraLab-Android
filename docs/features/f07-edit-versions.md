# F07 第四批：独立编辑版本与虚拟副本

日期：2026-11-13。本批完成同一原片的多个独立编辑版本。开发基线为已推送的 `af1b114`，本批纳入本次功能提交，尚未发布安装版本。

## 使用方式

在照片图库中打开照片菜单，选择“编辑版本”。默认版本保留现有调整，可以新建命名副本，也可以从其他副本继续复制；副本支持重命名和确认删除。打开版本会将它加入现有工作台，默认版与多个副本可同时存在，各自切换、保存、撤销、重做和勾选导出。

多个版本共享原片，各自保存调整。新建副本不复制照片文件，也不启动 RAW 解码或胶片渲染。相册、星级和色标属于原照片，由这些版本共享。

默认版本不能删除或重命名。仍在当前工作台中的副本需要先从工作台移除，再删除；失败提示说明具体操作，避免丢失正在编辑的内容。删除副本保留原片、默认编辑、其他副本和整理信息。名称支持 1 到 40 个 Unicode 字符，进行 NFC 正规化、去首尾空格和大小写无关去重；每张照片最多 30 个活动副本。

界面沿用 Theia 的圆润字体、暖纸色文字、琥珀色操作与原生圆角面板。版本列表可滚动，名称最多显示两行；新建操作独立显示，命名和删除使用原生对话框，保存中防止重复操作与误关闭。

## 代码与数据边界

实现按现有包结构分层：`core/model/EditVersion.kt` 定义版本身份；`data/library/EditVersionRepository.kt` 管理版本事务；`EditVersionProvider.kt` 提供应用内部只读原片访问；`feature/gallery/EditVersionsController.kt` 承接异步操作；`EditVersionsSheet.kt` 负责 Compose 界面。`EditStore` 仍作为编辑存储的统一串行入口，没有引入新的依赖或改造渲染引擎。

正式数据库在事务中从 v3 升级到 v4，新增 `virtual_edits`，保留已有默认编辑表、资产与默认版本 ID、参数和 revision。复制时核对源版本 ID、revision、完整参数和原片地址；旧面板操作不会覆盖变化后的数据。未来版本或无法识别的编辑数据保持原样，并拒绝不兼容的复制和修改。

默认编辑继续使用原 URI。副本采用稳定的私有 `content://com.spektralab.android.editversions/copies/<uuid>` 身份，复用现有逐图编辑、历史、预览和批量选择逻辑。Provider 在 Manifest 中明确不导出、不授予外部 URI 权限，拒绝写入，转交真实原片描述符并保留扩展名，不产生第二份源文件。原片重新关联后，副本仍通过资产找到新地址，版本身份不变。EXIF 访问回到真实原片，沿用原有位置保留策略。

导出缓存仍按真实原片的准入条件和指纹核对，副本不会使合法的本地 RAW 缓存失效，也不会放宽云端、管道或随机效果的缓存条件。

删除在同一事务中记录墓碑并清理持久工作台槽位。迟到的参数保存不能重建副本，迟到的工作台快照也会剔除已删除版本。工作台保留默认版及副本的顺序、当前项和导出勾选，旧会话格式继续兼容。撤销历史在当前进程中独立维护，尚不跨重启持久保存。

## 验证与性能

完整证据保存在忽略目录 `.tmp/edit-versions/verification.json`，构建、首轮与最终回归分别保留。最终同一生产构建完成 27 组、40 条功能记录，另完成大字体手机、平板和横屏三种配置。

- 真实旧 APK 创建 v3 数据后覆盖安装 v4，默认 ID、revision、亮度、裁剪、相册、标记和工作台保持；新副本关闭数据库后重开仍独立。
- 创建、复制、改名、取消、重复名称、过期状态拒绝、事务回滚、未知数据保护、原片重新关联及迟到写保护通过。
- 真实原生 UI 完成副本打开、切换、独立保存、撤销重做、分组参数复制、当前工作台删除保护及安全删除。Activity 重建并显式恢复后，默认版与副本、当前项和独立导出勾选保持。
- 四处真实进程终止覆盖新建和删除的提交前后；重开分别整体回滚或整体保存，删除与工作台清理保持一致。故障注入不替代真实满盘验收。
- 默认版与副本的完整 PNG 输出不同，各自的批量 PNG 与单张参考逐像素一致；JPEG、TIFF 批量导出及现有导入、编辑、胶片切换和导出回归通过。
- Z6II RAW 副本输出 6064×4040、16 位 TIFF，146992152 字节，完整 SHA256 为 `62f1d58c709a4bc694ca93f8d552954320f921260fc64dd4c013bf4461926f3f`，与原有参考一致。首次 9435ms，缓存 2835ms，缓存统计确认第二次命中；其他既有 RAW 摘要保持。
- 120 次默认保存中位数 0.834914ms、p95 4.12937ms，上一批为 0.792673ms、p95 3.961859ms；120 次副本保存中位数 1.172838ms、p95 4.881851ms。保留冷启动与长尾样本，全部为模拟器测量，不承诺真机固定速度。

管理版本只执行元数据 IO。默认版不走副本查询；预览和胶片渲染仍沿用原调度。1600×1067 预览测试中，中性、旧色调及曲线的像素摘要保持，耗时中位数分别为 19.78ms、100.16ms、72.40ms。胶片切换三轮数据与连续切换结果完整保留，不能据单轮波动声称真机提速。

6 项原生库、94 项引擎资源、2 项许可证素材及共享引擎源码与上一批逐字节一致；本批 Manifest 的预期变化是注册私有 Provider，生成的 dex 基线配置随 Kotlin 变化。没有降低尺寸、位深、RAW 解码质量、JPEG 质量或默认胶片效果。

候选安装包为 `app/release/v0.1.5-f07-edit-versions/Theia-v0.1.5-edit-versions.apk`，55562951 字节，版本仍为 0.1.5、versionCode 6，SHA256 为 `fb8282c49e793be92efacfe889bd6482f52922d8e7343f74b8ba5c34d1f8bee6`。原证书 V1、V2、V3 与双 ABI 通过。模拟器宿主使用匹配的调试代码与正式原生库；完整测试前后拉回 APK 的摘要相同，不将调试宿主等同于正式签名包的全流程安装验收。

独立界面审核检查 20 张原生截图，结论为 `ship`，未发现必须修复的视觉问题；触控与恢复行为由独立的功能测试覆盖。主题核对确认复用现有字体、色彩、圆角及 Material 组件，`DESIGN.md` 和 `.impeccable/design.json` 保持不变。核对记录了既有文档将 `TheiaShapes` 写作 `SpektraShapes` 的名称差异，本批未顺带修改主题文档。
