# F03 第六批：光晕输入与私有模糊累加器

日期：2026-11-12。基于已推送提交 644976b 继续开发。本批未提交或发布。

## 完成内容

一次性导出的光晕阶段消费输入图。镜头模糊完成后，将结果移动给光晕节点，散射混合更新 raw 时便能释放最初的输入，避免该图一直留到背反射结束。节点体从当前上游源码提取，只改变计数句柄的持有方式，原公式、分支、顺序和随机状态保持；普通编辑和条带执行仍使用原阶段。

Blur::mixture 仅为内部创建的私有累加图建立线程局部作用域。FIR 的垂直临时图和邻域输入保持独立，水平遍历最后的逐像素累加可写回旧累加器。混合 FIR/IIR 通道完全模糊后，最后的逐元素线性组合也可复用私有累加器。公开 gaussian、lincomb 的外部累加图保持借用；形状不同、对象不同、底层缓冲与邻域输入相同或有别名时拒绝复用。

IIR 递推的前后向扫描仍需要保留旧累加数据，未改写其输出或算术。保留每个节点及每个 mixture 分量的 flush。在分量 flush 之后增加一次性导出取消检查，取消不发布部分结果，不增加 GPU 同步。已有实验 FIR 分带保持默认关闭。

## 逐像素与取消验证

- 混合模糊独立程序 190 场景、63,901,737 个 Float 样本逐位相等，覆盖 FIR、IIR、混合通道、身份分量、零权重、正负权重、微小值、带符号零、边缘、不同截断范围和大图。FIR 私有写回 231 次，线性组合私有写回 63 次，确认真正经过优化分支。
- 完整源图和公开累加器检查未被修改；不同对象、相同底层缓冲和嵌套异常作用域的隔离检查通过。
- 混合模糊第 1、第 2、第 3 个分量后分别取消，要求准确停止、无部分输出、无活跃工作图。故障注入仅进入独立程序编译副本，不进入 APK。
- 光晕完整负片 120 场景、12,187,800 个 Float 样本逐位一致，覆盖负片、反转片、电影片、黑白，散射、背反射、关闭或零强度、不同混合比例、归一化开关、混合模糊范围、镜头模糊及颗粒。既有三个 DIR 内部取消检查点继续通过。
- 应用 36 组完整 U16 材料对照、已有负片缓存消费、真实取消及重新打开缓存恢复通过。

| 场景 | 上批渲染中位数 | 本批渲染中位数 |
