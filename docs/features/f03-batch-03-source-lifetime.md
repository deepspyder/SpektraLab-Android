# F03 第三批：源图生命周期与节点内存诊断

日期：2026-11-12。基于 F03 第二批未提交工作继续开发，本批未提交或发布。

## 本批改动

一次性导出完成测光、胶片负片及片边布局后，冲印节点已不再读取原始源图。Android 生成适配现在在冲印开始前清除源图、层级图及多余持有者。实际负片单独保留到冲印结束，RGBA16 输出继续拥有独立 CPU 存储。正常编辑、重印缓存、软打样和 DI 沿用原路径。失败和取消仍由一次性入口关闭会话。

在已有节点 flush 后加入默认关闭的内存诊断。仅 debug.theia.export_timings=1 时读取计数，不新增 GPU 提交或同步，不改节点、公式、顺序、位深、输出尺寸或默认效果。桌面引擎检出未修改。

## 实测收益与限制

24MP Z6II RAW 为 6064×4040。冲印开始前持久图由 315,103,004 字节降到 672,284 字节，释放 299.9 MiB，包含源图和层级测光图。此数是该阶段 GPU 持久缓冲计数的差值，并非进程总峰值或系统回收量。

全程临时池高水位保持 1401.8 MiB。第一次达到峰值的节点是 `node_dir_couplers(in.cur, in.log_e_film, next, error)`，在源图释放之前。本批降低冲印阶段的重叠驻留，未降低更早的 DIR 全局峰值，也不能宣称解决了全部大图卡死。

诊断中高水位为累计计数；后续节点重复该值不代表在那里新增峰值。池容量包含空闲图面，活跃图和持久图分别记录；CPU、驱动及其他进程分配仍需独立测量。
