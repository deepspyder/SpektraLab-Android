# F06：分组复制与命名编辑预设

日期：2026-11-13。本批承接 F05，现有通道混合和色轮已经随 cd3935f 推送到 master。F06 属于后续新开发，尚未提交或发布。

## 入口与操作

编辑器顶部点“更多操作”，选择“复制编辑设置”或“编辑预设”。导出页的复制入口也进入同一流程。

复制分两步：选择参数组，再勾选目标照片。默认选中其他照片，可逐张取消或清空；应用按钮显示实际有变化的数量。不需要重新应用的照片显示“设置相同”，无效目标给出具体原因。应用前的检查结果就是实际保存的参数集合，不能预览一种字段范围而写入另一种。

编辑预设支持创建、重命名、应用、确认删除和取消删除。保存当前参数时选择包含的组，应用预设时默认只选当前照片，也可以另选多张。名称最多 48 个字符，忽略首尾空白并阻止同名冲突；改名保留预设身份。预设与导出配方分别持久化。

页面沿用圆体、炭灰表面、暖纸文字、琥珀选中态和圆润控件；固定底部主要操作，内容可以滚动。打开、选组、选择目标及浏览预设不启动胶片显影，缩略图复用已有缓存。

## 参数组合同

| 参数组 | 内容 |
| --- | --- |
| 胶片与相纸 | 胶片和相纸的材料 ID |
| RAW 解码白平衡 | 自定义开关、色温、色调 |
| 拍摄与胶片效果 | 曝光测光、物理画幅、场景宽容度、颗粒、光晕、抗晕层、DIR、EDR、镜头滤镜 |
| 印放 | 打印曝光、Y 和 M 滤色、纸面光晕、预闪 |
| 光线 | 后期曝光、反差、亮度、高光、阴影、黑白点 |
| 曲线 | RGB、Luma、R、G、B 曲线 |
| 颜色 | 扫描白平衡、饱和度、HSL、自然饱和度、通道混合、新色轮及旧三段色彩平衡 |
| 暗角 | 强度、范围、羽化 |
| 构图与旋转 | 裁剪、直角旋转、拉直和翻转，默认不选 |
| 片边与日期样式 | 片边外观、日期后背开关及样式位置，默认不选 |

不复制原片身份、URI、EXIF、智能显影分析结果、自动日期的已解析文字、拍摄数据文字、片边帧号、光圈元数据和随机种子。几何只有明确勾选才会被模板覆盖；旧目标的局部数据保留。预设不含导出格式、质量、色域、尺寸、元数据开关和目录。

模板 version 1 使用明确字段白名单、参数组和类型校验。新增字段必须先决定组归属；范围、枚举、裁剪边界或工具版本不支持时不加载为可应用模板。中性曲线和颜色字段可以缺省，应用组时明确恢复中性，而不是遗留目标旧效果。

## 兼容性和保存

- 非 RAW 目标跳过解码白平衡，界面明确说明，其他所选参数仍应用。RAW 调整通过既有解码路径重新打开会话。
- 未知胶片或相纸跳过目标。材料类型不匹配且选择了材料组时，检查阶段选出兼容相纸并显示名称；没有合法相纸时跳过。未选择材料组时不会静默改掉目标搭配。
- 当前版本不认识的工具数据，不会进入可应用模板；目标未知颜色或曲线只有明确选择该组后才替换，并提示可通过撤销恢复。其他组的复制保持未知数据。
- 预设库中的未知记录原样保留，库根版本不支持或文件损坏时不覆盖原文件。照片 sidecar 的未知扩展字段保留在各自快照中，不传播到其他照片。
- 批量应用先核对所有目标的原记录，再把最终参数写入原子批次日志。任何目标在检查后变化时，整批拒绝，不发生前几张已经写入的半更新。
- durable commit 后逐张原子写入，异常中断后从日志幂等向前恢复。日志和普通 sidecar 读写使用同一串行锁；智能分析通过 saveIfAbsent 提交，不能覆盖晚于分析产生的手动设置。
- 批次只处理小型元数据，不解码所有原图。磁盘工作在 IO 线程，持久化同步只用于显式批量应用，普通滑杆保存保留原快速路径。
- 已加载目标追加一次可撤销历史，切换后仍能撤销到原调整；当前照片同步更新参数和画面。仅后期组复用冲印底图；RAW 白平衡重新解码；胶片或几何变化沿用现有渲染队列。
- 预览仍在运行或保存时暂不允许应用；批量提交期间锁定编辑身份，避免旧预览覆盖新批次。未松手的曲线、颜色、通道和色轮手势不进入模板。
