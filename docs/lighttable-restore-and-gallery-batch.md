# 观景台恢复与图库批量整理修复

日期：2026-11-14。

## 修复内容

- 观景台项目的照片源现在分开保存原始缩略图与已显影观片图。冷恢复工作台后，非当前照片继续显示已经完成的胶片、调色和片边效果。
- 再次保存已打开的观景台项目时，使用当前项目里的成片预览列表，不再把图库原片缩略图覆盖回项目。
- 旧项目没有 `rendered_preview` 字段时仍回退到原有 `preview`，不会破坏已有项目 JSON。
- 图库多选新增“加入相册”“加入观景台”和“加入观景台项目”。加入相册使用一个事务批量写入成员关系，原片和编辑记录不变；加入已保存项目保存照片引用和预览，不复制原片。

## 验证

在 Android Studio 使用的 `emulator-5554` 完成：

- 冷启动恢复工作台后，非当前照片仍保持显影预览比例和片边；编辑 JSON 未改变。
- 观景台项目再次保存不会替换已显影预览。
- 三张照片批量加入用户相册，成员关系完整，编辑 sidecar 保留。
- 既有观景台项目存储与 UI、图库相册存储与 UI 均通过。
- Kotlin 编译、模块边界和 `git diff --check` 通过。

Android Studio 的项目窗口已确认处于运行状态；本轮构建和仪器测试使用该项目的 Gradle 配置与同一模拟器完成。未提交或 push。

## 仍需注意

真机图库权限、跨设备 URI 授权、满盘和 ARM 性能仍需单独验收；这些不影响本轮数据一致性修复。
