# Theia Android v0.1.6

发布日期：2026-11-14

本版本在 v0.1.5 的基础上，补齐专业调色工具，完善数字暗房、观景台、图库和胶片模拟流程，重点加入 CineStill 800T 背反射光晕模型，并修复项目恢复后照片成片效果丢失的问题。

与 v0.1.5 实际发布包相比，曲线、色轮和通道混合属于本版本新增或正式补齐的调色能力。

## 主要更新

### CineStill 800T 与背反射光晕

- 新增 CineStill 800T 胶片配置和透明高清胶片标签。
- 基于原始 SpektraLab Vision3 500T profile 继承数据，不重复复制测量数组。
- 新增背反射光晕模型，模拟去除防光晕层后的反射效果。
- 增加经典光晕和背反射光晕切换。
- 增加 0–8 EV 高光余量控制，用于接近峰值高光的模拟补偿。
- 明确提示高光余量不会恢复原片已经丢失的细节，也不等同于 HDR。
- CineStill 没有防光晕层时，相关开关会显示为关闭并禁用，避免误操作。

### 胶片和相纸体验

- 胶片库加入 CineStill 800T 电影胶片分类。
- 胶片、相纸继续使用透明标签和照片编辑器式横向选择布局。
- CineStill 的胶片边文字显示为 `CINESTILL 800T`。
- 旧胶片、相纸和原有材料数据保持兼容。

### 观景台项目恢复修复

- 修复退出应用后恢复工作台，非当前照片回到原片预览的问题。
- 修复再次保存观景台项目时，原片缩略图覆盖胶片、调色和片边成片的问题。
- 项目现在分别保存原始预览和已显影预览。
- 恢复项目时优先显示已显影预览，保留胶片、调色、片边和比例。
- 旧项目没有新字段时自动兼容旧的预览字段。
- 观景台项目再次保存时使用项目内照片列表，不再错误读取图库原片列表。

### 图库批量整理

- 图库多选支持批量加入自建相册。
- 图库多选支持批量加入当前观景台。
- 图库多选支持批量加入已保存的观景台项目。
- 批量加入相册使用事务写入成员关系。
- 批量整理不会删除原片，也不会覆盖照片编辑参数。

### 编辑器与导出

- 新增曲线调节工作区，支持 RGB、红、绿、蓝通道曲线编辑。
- 新增色轮调节，支持阴影、中间调和高光的色彩控制。
- 新增通道混合，支持 RGB 通道比例调整。
- 曲线、色轮和通道混合接入预览、保存、撤销、复制、预设和导出。
- 胶片、光晕模型、高光余量参数接入保存、撤销、重做、复制、预设和缓存。
- 单张和批量 PNG、JPEG、TIFF 导出继续保留原始尺寸合同。
- 24MP RAW 全尺寸 16 位 TIFF 导出验证通过。
- 保持原有 RAW 解码、胶片显影、相纸输出和编码质量。

### 横屏布局

- 短横屏编辑器隐藏重复的照片信息和面板标题。
- 保留胶片、相纸入口，为参数面板释放更多可用高度。
- 胶片和光晕控制在横屏下仍可滚动访问。

## 兼容性与数据安全

- 旧编辑记录默认使用经典光晕模型，不会自动迁移到新模型。
- 未知或无效的光晕模型版本会拒绝读取，不会静默降级。
- 旧观景台项目 JSON 保持兼容。
- 原片、编辑记录、图库关系和观景台项目彼此独立保存。

## 已知限制

- ARM 真机 GPU 驱动、温控和持续性能仍需单独验收。
- 50MP、超宽图和极端内存压力仍属于 F03 后续范围。
- 高光余量是模拟补偿，不是 HDR 或丢失细节恢复。
- 本版本不包含 F10 半格双图项目。
