# SpektraLab Android v0.1.2 · 大图导出优化与关于页面

SpektraLab Android 是一款免费开源的胶片与暗房模拟应用，支持胶片和相纸模拟、RAW 导入、照片调色，以及带片边的图像导出。

## 本次更新

### 修复与优化
- 修复大尺寸 JPEG 和 RAW 导出时，整幅像素数组耗尽 Java 堆内存而引发的闪退。
- 导出输入和渲染结果使用 Native 内存管理，保存时按 32 行分块读取，减少 Java 堆中的整幅像素副本。
- 提前释放 RAW 解码工作缓冲和导出 GPU 会话，减少解码、渲染及编码阶段的资源重叠。
- RAW 按实际图像尺寸选择合适的解码方式；选择“原始”时保留原始导出分辨率。
- RAW 编辑预览在 Native 解码阶段限制为 2048px 长边，避免 50MP RAW 导入预览时创建超出 ART 堆余量的整幅像素数组；全尺寸导出仍使用完整 RAW 数据。
- `.tif` / `.tiff` 文件会检查 TIFF DNGVersion 标签，识别被传输软件改成 TIFF 后缀的 DNG，并交给 LibRaw 解码。
- 完善导出异常记录、进度显示，以及取消和失败时的资源清理。
- 为原生渲染库启用 16KB 内存页对齐配置，改善安装包对新设备的兼容性。

## 下载与安装
- 安装包：`SpektraLab-Android-v0.1.2-universal.apk`。
- 系统要求：Android 8.0（API 26）及以上。
- CPU 架构：`arm64-v8a`、`x86_64`；不包含 32 位 ARM。
- 渲染使用 Vulkan，实际可用性取决于设备 GPU 和驱动支持。
- 请从本项目 Release 页面下载安装包。升级现有版本时，需要使用相同的应用签名。

## 验证与已知限制
- 调试构建已通过 arm64-v8a 和 x86_64 编译；运行验证在 x86_64 模拟器完成。
- 已使用 `androidTest/assets` 中的 8192×6144 JPEG（13.65 MB）和 50MP Xiaomi `raw.dng` 实测：分别全尺寸导出和双图全尺寸批量导出均通过，输出为 6144×8192。
- 提供的 33.67 MB DNG TIFF（`.tiff` 后缀）现会识别为 RAW 并通过 LibRaw 导出为 6144×8192；旧版按普通 RGB TIFF 处理，仅解码到 1536×2048（约 3.15MP）。
- 两种 50MP DNG 的编辑预览均限制为 1536×2048。修复前，ART 堆仅余约 25 MB 时申请 50,331,664 字节 ARGB 预览缓冲并 OOM，崩溃发生在打开照片阶段。
- 另已验证 3072×4096 JPEG 与约 40.56 MB、5200×3900 合成 DNG 的原始尺寸导出。
- 已验证片边、PNG、Display P3 TIFF、像素对照，以及导出取消和进度清理。
- Native/Managed RAW 像素一致性、透明位图输入及分块 TIFF 字节一致性回归均通过。
- 合成 DNG 只验证解码和内存路径，不代表所有相机厂商的 RAW 格式均已逐一测试。
- 50MP 模拟器批量渲染的引擎瞬时 scratch 高水位约 3.94 GiB。目标 Xiaomi 设备的 `Vulkan compute dispatch failed (VkResult -4)` 尚未能真机复现，手机 GPU/驱动内存压力仍有风险；本版修复了确认的 ART 预览 OOM 和 DNG TIFF 误识别，不宣称所有设备上的 Vulkan device-loss 都已解决。
