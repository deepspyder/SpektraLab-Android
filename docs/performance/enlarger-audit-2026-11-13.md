# 放大机与暗房功能核对

日期：2026-11-13。本批检查现有功能并修复边界问题，没有推进 F10，也没有修改胶片、相纸模型或照片质量参数。

## 检查结论

| 功能 | 结果与验证范围 |
| --- | --- |
| 打印曝光 | 0.25 至 4 的边界与中间值通过，数值越小成片越亮；单位为打印曝光倍率，不是拍摄 EV |
| Y、M 滤色 | 两轴正负 40 CC 及组合调节通过，显示值与实际参数对应 |
| 相纸切换 | 最终正式重印与独立新会话的全量显影逐样本一致，小 LUT 没有覆盖最终结果 |
| 预闪、EDR | 使用有亮部刺激的输入验证实际像素变化；低动态照片不作为效果无效的判据 |
| 颗粒、光晕、抗晕层、DIR、纸面光晕 | 既有 native 与效果基线回归通过，未改变模型或随机约定 |
| 片边与日期后背 | 既有画幅、方向、样式、位置等 native 回归通过 |
| 真实控件、撤销、保存、重开 | 使用生产 PrintPanel 的滑块无障碍动作调节曝光与 Y/M，撤销、重做、侧车保存和重开保持 |
| 原图、单张及批量导出 | 前批原图显示修复、PNG/JPEG/TIFF 与全尺寸 RAW 质量回归通过 |

新增 12 组放大机参数组合，分别验证曝光、Y/M、组合、预闪、EDR 和相纸。每组快速重印都复用负片，并与独立新会话的完整 U16 全量渲染逐字节相同。专项计时仅为小尺寸模拟器样本，不用于承诺手机速度。

自动配光的现有行为是重新测光、恢复中性滤色，归零用户的 Y/M 偏移；保留手动拍摄曝光补偿和打印曝光，不把测光结果再次叠加造成双重曝光。已经处于中性滤色时，重复操作的外观变化可能很小。

## 发现与修复

1. 导出已经占用引擎时，自动配光和宽容度分析仍可能被接受。修复前专项明确失败；现在单张导出、批量导出和批量应用期间均拒绝这些分析，场景置位应用也遵守状态限制。
2. 宽容度测量完成的回调没有绑定照片代次。即使重新打开相同 URI，旧结果也可能写入新一轮编辑。现在分析在进入引擎队列前后都核对照片代次、URI 和请求参数快照；过期结果不写入，新照片的加载状态也不会被旧回调清除。取消和异常由统一 finally 清理。
3. 黑白相纸和正片原本会在 native 参数构造时关闭 EDR，但界面仍允许切换，容易误以为无效。现在明确显示禁用、关闭状态及“仅彩色负片搭配彩色相纸时可用”。保留用户原先的彩色 EDR 选择，回到支持的材料组合后恢复。没有新增物理限制，也没有改动 EDR 计算。

生产变更限定于 EditorViewModel 的分析调度、PrintPanel 的 EDR 可用状态、ToggleRow 的默认兼容 enabled 参数及一条资源化提示。普通开关继续默认启用，字体、圆角、配色和页面结构沿用现有主题。
