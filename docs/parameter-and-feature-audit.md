## 本轮确认并修复的问题

| 问题 | 触发条件与旧行为 | 修复后的行为 |
| --- | --- | --- |
| 未完成曲线/HSL手势被保存 | 先前的拍摄/材料渲染在手势中保存当前参数；取消后磁盘可能仍保留临时点或颜色 | 保存和历史只包含已提交的后期设置；实时预览继续使用手势值，松手正常提交，取消和重新打开保持正确 |
| 小裁剪完成后范围变大 | 裁剪控件允许2%选区，完成时却分别将宽高限制到10%，破坏小选区及比例 | 提交使用与控件一致的2%下限，已有效的选区坐标不被额外放大 |
| 裁剪撤销后比例锁错误 | 撤销从正方形回到电影比例时坐标恢复，界面仍锁定1:1 | 几何变化时同步恢复为原始/自定义，后续拖动不沿用错误比例；无关调色撤销保留原比例选择 |
| 批量导出后停在旧预览 | 调参后立即批量导出；恢复调用位于批量循环内，被正在导出的状态拦截 | 释放批量状态后恢复一次待处理拍摄/后期工作；成功及取消均验证，输出像素保持 |

新增7项边界测试在未修复安装包全部失败，修复后全部通过；另补充检查取消后的撤销/重做、重新打开、独立曝光保留及正常手势提交。没有仅删除或放宽原有断言。
